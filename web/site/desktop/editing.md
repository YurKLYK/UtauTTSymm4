# 抑揚と長さの編集

<!--@include: ../shared/editing.md-->

## 原音ごとの数値設定

「設定」→「設定...」で「拡張編集で数値設定を表示する」を有効にすると、選択した原音を数値で調整できます。

対象はOffset、Cutoff、Consonant / Fixed、Preutterance、Overlap、ピッチ係数、音量係数、Velocity、Volume、Modulation、Tempo、Flagsです。通常は変更する必要はありません。
