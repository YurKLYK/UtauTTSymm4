# 英語・中国語の読み上げ

日本語のほかに、英語と中国語の文章も読み上げられます。音源に収録されている発音に合う言語と発音形式を選んでください。普通は自動で問題ないです。

## 言語と発音形式

カードの設定で「言語」を選びます。「発音形式」は、入力した読みを音源の原音名へ変換する方式です。普通は自動で問題ないです。

| 言語 | 発音形式 | 対応する音源 |
| --- | --- | --- |
| 日本語 | かな（`ja-kana`） | 日本語のUTAU音源 |
| 英語 | ARPAsing（`en-arpasing`）、Delta（`en-delta`）、VCCV（`en-vccv`）、C+V（`en-cv`） | それぞれの形式で収録した英語音源 |
| 中国語 | CVVC（`zh-cvvc`） | 中国語のCVVC音源 |

## 読みを直す

自動の読みが違う語は、[辞書設定](/desktop/settings#辞書設定)で読みを登録します。英語は英単語の発音記号（ARPAbet）、中国語は声調付きのピンインで書きます。

| 言語 | 読みの例 |
| --- | --- |
| 英語 | `HH AH0 L OW1 \| W ER1 L D` |
| 中国語 | `ni3 hao3` |

英語の母音の後の数字は強勢で、`0`が強勢なし、`1`が第一強勢です。中国語の数字は声調です。

英語・中国語の読みの決め方や、コマンドライン版での指定方法は[日本語・英語・中国語の読み上げ](https://github.com/yh2237/UtauTTS/blob/main/docs/multilingual.md)を参照してください。
