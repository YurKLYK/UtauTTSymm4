# UtauTTS

UtauTTSは、UTAUボイスバンクの原音接続に学習ベースのイントネーション調整を加えたTTSです

Windows、mac、Linuxに対応したデスクトップ版と、Web版があります。



## 使い方

- [デスクトップ版の使い方](/desktop/): インストールから書き出し、設定まで
- [Web版の使い方](/web/): エディタの開き方から保存、スマートフォンでの操作まで
- [利用条件とライセンス](/terms): UtauTTSのライセンス
