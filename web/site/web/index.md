# はじめに

UtauTTSは、UTAUボイスバンクの原音接続に学習ベースのイントネーション調整を加えたTTSです。Web版はブラウザで[エディタ](/editor/){target="_self"}を開くだけで使えます。パソコンに入れて使う[デスクトップ版](/desktop/)もあります。

## 動作環境

- Chrome・Edge（多分他もok）
- 初回はエンジン・辞書・抑揚モデルなど、合わせて100MB以上を読み込みます。Wi-Fiに繋がっている環境で行ってください。
- 音声合成はすべてブラウザの中で行います。入力した文章や追加した音源はサーバーに送信されません。

## 使い方

1. [エディタ](/editor/){target="_self"}を開き、読み込みが終わるまで待ちます。
2. 左上のカードに文章を入力します。入力すると自動で読みと抑揚を付け、画面下のグラフに表示します。（端末の性能によってはそこそこ時間がかかります。）
3. 画面下の再生ボタンを押すと、音声を作って再生します。パソコンでは`Ctrl+Enter`でも再生できます。
4. 気に入ったら「ファイル」→「書き出し」→「WAVを保存...」でダウンロードします。

最初は同梱の音源「足立レイ」で話します。ほかの音源を使う方法は[基本の使い方](/web/basics#音源を追加する)を参照してください。
